# Math for Machine Learning: Linear Algebra - FinMark Corporation ML Solution

This repository holds the coursework and project for **Math for Machine Learning: Linear Algebra**, a 3-unit course focused on the foundational linear algebra concepts crucial for machine learning. This course emphasizes how to represent and manipulate data using vectors, matrices, and tensors, providing a geometric understanding essential for grasping various data analysis and modeling algorithms.

## Course Overview

This course builds a strong mathematical backbone for machine learning, enabling learners to:

* Collect and preprocess data from diverse sources, ensuring quality and consistency.
* Apply statistical reasoning and data analysis techniques to uncover trends, correlations, and patterns within datasets.
* Extract actionable insights from analysis results to inform decision-making.

## FinMark Corporation Machine Learning Solution Project

The core of this course culminates in a group project addressing a real-world issue for the fictional **FinMark Corporation**, leveraging both machine learning and linear algebra concepts. This project is designed to enhance technical and analytical skills, fostering proficiency in data analysis and machine learning.

The project development is structured through the following key milestones:

### Milestone 1: Exploratory Data Analysis (EDA) of Machine Learning Solution Project

This phase involves a thorough exploration of the collected FinMark Corporation datasets. The objective is to understand the main characteristics of the data, identify key patterns, and detect any anomalies that may impact subsequent modeling.

### Milestone 2: Data Visualization on Machine Learning Solution Project

Following EDA, this milestone focuses on creating compelling data visualizations. These visualizations are crucial for discovering relationships between variables and clearly identifying patterns and trends within the FinMark Corporation datasets.

### Terminal Assessment: Presentation of Machine Learning Solution Project

The final deliverable is a comprehensive presentation detailing the entire development process of the machine learning solution, from data understanding and preprocessing to model insights and findings for FinMark Corporation.
